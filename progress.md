## How to Use This Progress Tracker

### Starting a New Session:

1. **Choose a path:**
   - `learning` → We'll go through topics sequentially per the phased plan
   - `interview_practice` → I'll pick a question from the 18 interview questions

2. **I'll check the progress.md** to see where we left off last time

3. **We'll dive into the topic** and update the relevant MD file(s) with:
   - Deep discussion
   - Any new Mermaid diagrams
   - Key takeaways
   - Updates to completion status

4. **At the end of session**, we'll update progress.md:
   - Mark the topic as completed
   - Note the current focus/learnings
   - Record the choice for next time

### Resuming from Last Session:

- Open `progress.md` - it will show the last completed topic and current focus
- We continue from that exact point
- No need to re-cover already-discussed material

### Path Switching:

- You can switch between `learning` and `interview_practice` any time
- Each path maintains its own progress independently
- The `reference_plan.md` guides the learning path structure
- The `06-interview-questions.md` drives the interview practice path
